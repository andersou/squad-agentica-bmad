# Squad agêntica com BMAD

Apresentação sobre como usar o [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD) v6 como squad agêntica, do primeiro comando ao dia a dia, e o projeto de exemplo construído com ela.

## Conteúdo

- `docs/bmad-squad-agentica.html`: slides (abra no navegador).
- `docs/bmad-squad-agentica.pdf`: os mesmos slides em PDF.
- `api-tarefas/`: API de tarefas feita com a squad, do PRD à retrospectiva. Os artefatos de planejamento e implementação ficam em `api-tarefas/_bmad-output/`. Veja o [README](api-tarefas/README.md) para instalar, testar e rodar.
